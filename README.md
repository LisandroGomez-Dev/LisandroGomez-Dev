## 📌 Proyectos destacados

### Motor de Gestión de Inventario con Bloqueo Optimista

API REST desarrollada en Java 21 con Spring Boot 3, orientada a prevenir la sobreventa y evitar condiciones de carrera mediante control de concurrencia optimista. El proyecto incluye un simulador en React para generar peticiones concurrentes y observar el comportamiento del sistema bajo carga.

Stack: Java 21, Spring Boot 3, JPA/Hibernate, PostgreSQL, Flyway, Docker Compose, React.

- Control de concurrencia optimista usando `@Version` en JPA/Hibernate.
- Manejo de conflictos con respuesta `409 Conflict` ante versiones desactualizadas.
- Migraciones con Flyway y despliegue local con Docker Compose.
- Simulador frontend para pruebas de concurrencia y comportamiento en tiempo real.

Repositorio: https://github.com/LisandroGomez-Dev/motor-gestion-inventario-bloqueo-optimista

### TurnoFácil

Sistema de reserva de turnos con flujo de pago y estados de transacción. Participé en el backend, donde implementé la lógica principal del manejo de reservas y pagos.

Stack: Next.js 14, Express, TypeScript, TypeORM, MySQL, Mercado Pago.

- Flujo de pago con estados `PAGO_PENDIENTE`, `CONFIRMADO` y `CANCELADO`.
- Implementación del backend para reservas y pagos.
- Modelado de estados y comportamientos mediante patrones State y Strategy.
- Enfoque en la organización de la lógica de negocio y la separación de responsabilidades.

Mi aporte: desarrollé el flujo de pagos y la lógica de estados de turno, coordinando la parte del backend del sistema.

Repositorio: https://github.com/LisandroGomez-Dev/sistema-turnos-isii-grupo38

Stack: C#, .NET Framework 4.7.2, WinForms, SQL Server.

- Arquitectura en capas: UI, Domain, Data y Services.
- Implementación del patrón Repository.
- Funcionalidades de login con BCrypt, backups, ventas, productos, clientes e inventario.
- Énfasis en la claridad de diseño y la organización del dominio.

Mi aporte: desarrollé el módulo de ventas y la autenticación con BCrypt.
